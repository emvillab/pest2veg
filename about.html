About Pest2Veg

Purpose

Pest2Veg is a front-end educational prototype designed to help UK growers explore a selected range of common crop pests. It supports six crops: tomato, cabbage, potato, lettuce, pepper and cucumber.

How identification works

The user chooses a crop, visible damage and the location of that damage. Simple JavaScript compares those choices with the pest dataset and displays possible matches. It does not calculate a probability or make a diagnosis.

SDG 2: Zero Hunger

The project links to UN Sustainable Development Goal 2 by promoting access to crop-pest information and awareness of responsible crop management.

Limitations

This prototype contains a selected set of pests rather than an exhaustive UK pest database. Pest symptoms can overlap, so users should confirm identification using trusted horticultural or agricultural guidance before taking action.
